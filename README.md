# Tamagotchi

Груповий проєкт з курсу «Introduction to Programming». Автори: Daria-Pliskovska, venhel-ukma.

Репозиторій: https://github.com/Daria-Pliskovska/tamagotchi

## Мета

Тамагочі, написаний мовою C. Вихованець (піксельний зайчик) поводиться як малюк і сам нічого не вміє. За ним доглядає AI-помічник: пам'ятає, коли його нагодувати, перевдягти, пограти з ним і вкласти спати. Користувач може робити це сам або вимкнути помічника і доглядати самостійно.

## Короткий опис

У репозиторії дві версії програми з однаковою логікою гри:

- `main/` — версія для комп'ютера: вікно у вигляді рожевого джойстика (бібліотека raylib).
- `simulator/` — версія для плати Arduino Mega з екраном ILI9341, яка запускається в онлайн-симуляторі Wokwi. Увесь код на C, без сторонніх бібліотек.

У зайчика п'ять показників: HUNGER (ситість), DIAPER (чистота), FUN (настрій), ENERGY (енергія), HEALTH (здоров'я). Вони поступово падають, і зайчик показує це емоціями: хоче їсти, позіхає, плаче, спить.

## Як установити і запустити

### Версія в симуляторі

Нічого встановлювати не треба.

1. Відкрити https://wokwi.com/projects/480122784162707457
2. Натиснути зелену кнопку запуску.

### Версія для комп'ютера (Linux або WSL Ubuntu)

1. Встановити компілятор і залежності:

```
sudo apt update
sudo apt install build-essential git libasound2-dev libx11-dev libxrandr-dev libxi-dev libgl1-mesa-dev libglu1-mesa-dev libxcursor-dev libxinerama-dev
```

2. Встановити raylib 5.5:

```
git clone --depth 1 --branch 5.5 https://github.com/raysan5/raylib.git
cd raylib/src
make PLATFORM=PLATFORM_DESKTOP
sudo make install
```

3. Зібрати і запустити гру:

```
cd main
make run
```

## Приклад використання

| Дія | Комп'ютер | Симулятор |
|---|---|---|
| Нагодувати | A | кнопка A |
| Перевдягти | B | кнопка B |
| Пограти | X | кнопка X |
| Вкласти спати | Y | кнопка Y |
| Показати статистику | S | кнопка STATS |
| Увімкнути або вимкнути AI | I | кнопка AI |
| Почати заново | R | кнопка RESET |
| На весь екран | F11 | немає |

У версії для комп'ютера кнопки також можна натискати мишкою.

Приклад: зайчик показує хмаринку з морквою, отже він голодний. Натисніть A: у верхньому рядку з'явиться «You: feeding», і зайчик почне жувати моркву. Якщо AI увімкнений, він нагодує зайчика сам, і в рядку буде «AI: feeding».

## Важлива інформація

- Час у грі йде швидше: одна секунда дорівнює двом ігровим хвилинам.
- Якщо AI вимкнений і зайчика перегодувати, він товстішає. На екрані STATS це видно як додаткові помаранчеві клітинки HUNGER. Коли вони зникають, зайчик худне.
- Якщо зайчик довго не спить, він починає істерику («NO!!») і через 60 ігрових хвилин тікає («RAN AWAY!»).
- Якщо здоров'я падає до нуля, гра закінчується («GAME OVER»). Почати заново можна кнопкою RESET.
- Поки зайчик спить, грати з ним не можна. Годування його будить.
- Версію для комп'ютера треба запускати з папки `main/`, бо поруч має лежати файл `background.png`.
- У WSL вікно гри іноді відкривається порожнім. Тоді в PowerShell треба виконати `wsl --shutdown` і запустити гру ще раз.
- У симуляторі екран малюється повільніше, ніж на справжній платі, а перша збірка може кілька секунд чекати в черзі.
